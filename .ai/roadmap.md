# FIP Core MVP — Roadmap

## Fase 1 — Fundação
- Criar repositório
- Configurar Docker
- Configurar PostgreSQL
- Configurar Prisma
- Criar estrutura modular
- Criar autenticação básica
- Criar usuários e permissões

## Fase 2 — Financeiro interno
- Criar títulos financeiros
- Criar importação manual de títulos
- Criar listagem e filtros
- Criar status financeiros

## Fase 3 — Gateway Rede
- Criar módulo Rede
- Criar cliente HTTP configurável
- Criar mocks de payload
- Salvar payload bruto
- Normalizar transações e recebíveis

## Fase 4 — Conciliação
- Criar motor de score
- Criar conciliação automática
- Criar divergências
- Criar conciliação manual
- Criar reversão auditada

## Fase 5 — Painel
- Dashboard
- Títulos
- Recebíveis Rede
- Conciliação
- Divergências
- Auditoria
- Jobs
- Payloads

## Fase 6 — Relatórios
- Exportação Excel
- Relatório de divergências
- Relatório de conciliações
- Relatório de recebíveis

## Fase 7 — Preparação para novos gateways
- Criar interface comum de gateway
- Documentar como adicionar novo gateway
- Criar módulo template para futuro gateway

## Fora do MVP
- Microsserviços
- Multi-tenant
- Observabilidade avançada
- Multi-gateway em produção
- Kubernetes
- Event Sourcing completo
